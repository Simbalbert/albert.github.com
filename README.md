# DUSENGE Simon Pierre - Personal Portfolio

A personal portfolio website for Eng. DUSENGE Simon Pierre, an ICT professional and Software Developer. The site introduces who I am, highlights my background, and showcases the projects I've worked on in software development, database management, IT infrastructure, and healthcare information systems.

## Features

- About Me section: a short professional bio and profile photo
- Projects section: a list of personal and academic projects, organized into categories
- Simple, lightweight design built with plain HTML and CSS (no frameworks required)
- Fully static site, deployable for free via GitHub Pages

## How to run this project

This project is live and can be viewed directly at:

**https://piesimon.github.io/dusengesimonpierre_portfolio/**

You can also run it locally on your own machine by following the steps below.

### Prerequisites

- [Git](https://git-scm.com/downloads) installed on your machine
- A modern web browser (Chrome, Firefox, Edge, etc.)
- (Optional) [Visual Studio Code](https://code.visualstudio.com/) with the **Live Server** extension, for easier local previewing

### Installation

1. Clone the repo:

   ```
   git clone https://github.com/piesimon/dusengesimonpierre_portfolio.git
   ```

2. Navigate into the project folder:

   ```
   cd dusengesimonpierre_portfolio
   ```

3. Open `index.html` directly in your browser, **or** open the folder in VS Code and use the Live Server extension for a live preview.

4. To make changes: edit `index.html` (content) and `styles/main.css` (styling), save, then commit and push:

   ```
   git add .
   git commit -m "your message"
   git push origin main
   ```
